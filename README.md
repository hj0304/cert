# 🎓 CERT — 나만의 자격증 문제은행

ADsP · 정보처리기사(예정) 기출 문제은행. **광고 없이, 깔끔한 UI로.**

## 특징

- **Bento grid 대시보드** — 학습 통계, D-day, 오답노트, 북마크를 한눈에
- **🔍 문제 검색** — 1,735문제를 키워드로 검색 (다중 단어 AND, `"정확한 문구"`), 자격증·유형 필터, 검색 결과만 몰아서 풀기
- **📴 오프라인 학습** — 전 회차를 한 번 저장하면 데이터 없이도 풀이·검색 가능 (PWA 서비스 워커)
- **코드 문법 하이라이팅** — 실기 C/Java/Python/SQL 코드 187블록에 색상·줄번호 (외부 라이브러리 없음)
- **🎨 디자인 스킨 10종** — 기본 Bento 외에 Glassmorphism, Claymorphism, Skeuomorphic, Grainy, Brutalist, Cyberpunk, Y2K, Retro-Futurism, Duotone 중 취향대로 선택 (상단 🎨 버튼)
- **연습 모드** — 문제별 "정답·해설 확인" 버튼으로 확인 (선택 없이 누르면 열람만 — 기록 미반영)
- **실전 모드** — 전체 풀고 제출하면 채점, 과목별 점수 · 과락(40%) · 합격(60점) 판정
- **⏱ 시험 시간 카운트다운** — 실제 시험시간(ADsP 90분 / 필기 150분 / 실기 150분)을 카운트다운, 10·5·1분 남으면 경고, 시간 종료 시 자동 제출
- **📚 과목별로 풀기** — 회차에 들어가면 상단 과목 필터로 그 회차의 특정 과목만 골라 풀 수 있고(예: 42회 · 데이터 이해 10문제), 회차 선택 화면에서는 전 회차의 한 과목을 몰아서 풀 수 있어요 (ADsP 3과목 / 필기 5과목)
- **🎯 D-day 학습 계획** — 2026년 시험일정이 내장돼 회차만 고르면 설정 완료. "남은 문제 ÷ 남은 일수"로 하루 목표를 역산하고 오늘 진행률을 추적 (정처기는 CBT 기간제라 응시 기간 중이면 마감일 기준으로 계산)
- **해설 수록** — 1,359문제 중 94%에 해설 포함 (등록자 해설 + AI 해설, 위키 링크)
- **AI 오답노트 (비용 0)** — 오답·북마크 문제를 프롬프트와 함께 클립보드로 복사해 Claude/ChatGPT에 붙여넣기
- **🌱 스마트 복습 (간격 반복)** — 맞히면 1→3→7→21일 뒤, 틀리면 다음날 자동으로 복습 목록에 등장 (망각곡선 기반)
- **🎯 약점 저격 모드** — 과목별 정답률이 낮은 영역·최근 틀린 문제 위주로 20문제 가중 추출
- **합격 예측** — 학습 기록으로 과목별 예상 점수와 과락 위험을 대시보드에 표시
- **전국 정답률 배지** — 정답 공개 후 문제별 난이도 표시 (정답률 40% 미만 🔥 킬러 문제)
- **랜덤 20문제 / 오답노트 / 북마크** 복습 모드
- **🔔 복습 알림** — 복습할 문제가 생기면 브라우저 알림 (Chrome/Edge는 백그라운드 하루 1회, 그 외는 방문 시). PWA로 설치 가능
- **🔥 학습 스트릭** — 연속 학습일·최고 기록 배지, 14일 활동 그래프
- **기록 백업** — 학습 기록 JSON 내보내기/가져오기로 기기 간 이동
- **다크모드**, 키보드 단축키(1–5 선택, ←/→ 이동, Enter 확인, B 북마크)
- 모든 학습 기록은 브라우저 `localStorage`에 저장 (서버 없음)

## 수록 문제

| 자격증 | 회차 | 문제 수 |
|---|---|---|
| ADsP (데이터분석 준전문가) | 31~42회 (12회분) | 560문제 (단답형 57 포함) |
| 정보처리기사 필기 | 2020년 1회 ~ 2022년 2회 (8회분) | 799문제 |
| 정보처리기사 실기 | 2020년 1회 ~ 2025년 3회 (19회분) | 376문제 (필답형 복원) |

> - ADsP 34회 22·46번, 33회 일부 등은 원본 복원 데이터 자체에 없는 문항입니다.
> - 정처기 필기는 2022년 3회부터 CBT로 전환되어 이후 기출이 공개되지 않습니다. 수록된 8회분은 **현행 출제기준(2020년 개정 5과목)** 공개 기출 전체이며, 이 출제기준은 2026년까지 유지되고 2027년 전면 개편 예정입니다.

## 실행

정적 사이트라 빌드가 필요 없습니다. `index.html`을 열거나 아무 정적 서버로 서빙하면 됩니다.

## 배포 (GitHub Pages)

1. 이 폴더를 `https://github.com/hj0304/cert` 에 push
2. 저장소 Settings → Pages → Branch `main` / root 선택
3. `https://hj0304.github.io/cert/` 접속

## 구조

```
index.html          # 홈 (bento grid 대시보드)
exam.html           # 회차 선택 + CBT 풀이 화면
search.html         # 문제 검색
sw.js               # 서비스 워커 (오프라인 캐싱 + 복습 알림)
css/style.css       # 디자인 시스템 (bento grid, 다크모드, 코드 하이라이팅)
css/skins.css       # 디자인 스킨 9종
js/common.js        # 자격증 레지스트리, 저장소, SRS, 테마·스킨, 오프라인
js/home.js          # 대시보드 로직
js/exam.js          # 풀이/채점/모드 로직
js/search.js        # 검색 로직
js/codehl.js        # 코드 문법 하이라이터
data/{cert}/        # 회차별 문제 데이터 (JS 래핑 — file:// 에서도 동작)
data/index.js       # 검색 인덱스 (tools/build-index.js로 생성)
tools/bump.js       # 배포 전 캐시 버스팅 버전 스탬프
tools/build-index.js # 검색 인덱스 재생성
```

배포 전에는 `node tools/build-index.js && node tools/bump.js`를 실행해 인덱스와 캐시 버전을 갱신합니다.
